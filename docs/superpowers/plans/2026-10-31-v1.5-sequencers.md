# v1.5: piano roll, evolving sequencer, transport (session 9, 2026-10-31)

Owner: "a (/multiple) better sequencer module ... a more intuitive piano roll one that also has a
built in clock and a button to switch on/off as well as hooked to the global play button and can do
notes of different length (and 16th notes etc)? And maybe one that can organically evolve the line.
Like the current sequencer you can't even change the root note." For a demo video.
Mode: speed over ceremony (build, then list the calls); Claude inline + one Opus reviewer.

## Tasks
1. **Transport** (`core/transport.{h,cpp}`): global play/stop + an epoch that bumps on every start.
   Space in the patch view toggles it when the patch has a ROL or EVO (a stopped transport always
   restarts on Space). CLK, ROL, EVO and the ClockIn sequencers (SEQ TRG EUC TUR) follow it: stopped =
   no clock, start = everything back to step 1 together. Every load / NEW plays.
2. **SEQ gets ROOT and OCT** (SET page), so the 12-step pattern transposes.
3. **ROL** (piano roll, `core/modules/seq2.cpp`): 32 steps, one mono note per step with ties, so a
   note lasts 1..32 steps; RES = 1/4 1/8 1/16 1/32 8T 16T; built-in clock (BPM, swing) or CLK in;
   RUN on/off; ROOT/SCL/OCT transpose the stored notes; GLN, glide. Notes are packed 3 steps per
   param (7 bits each) in 11 params, so save, load, undo and presets need no new format.
4. **ROL roll page** (Play page, raw keys): rows 2-4 = the scale as a keyboard (writes a note of the
   chosen length at the cursor, plays it, advances); number row = lengths 1..16 steps, REST, TIE,
   octave -/+; ctrl/space = cursor; del = erase note (fn: clear all); enter = RUN (fn: global
   play/stop); fn+pitch = preview only; fn+length = resize the note under the cursor.
5. **EVO** (evolving line): 2..16 steps grown from SEED as a random walk in the scale; at each pass
   end every step mutates with MUT (pitch walk with GRV pulling home, rest/note by DNS, ties,
   motif echoes, accents). A start (transport) replays from the seed, so each take is the same.
6. Pictures (roll, EVO line), side icons, tile step bars, 3 presets, spec section 16.

## Calls made (owner can veto)
| Topic | Call |
|---|---|
| Module names | ROL (piano roll), EVO (evolving) on the MOD page |
| ROL size | 32 steps (2 bars of 1/16, 4 of 1/8); bigger needs a patch-format change |
| Mono | one note per step (the synth is mono) |
| RUN off | mutes the gates but keeps counting, so it comes back in time |
| Space priority | stopped -> play; ROL/EVO in patch -> stop; else KEYS audition; else KIT pass |
| EVO restart | a start replays from SEED (repeatable takes); MUT 0 freezes it |
| EVO memory | the evolved line is not saved (only its params); same seed = same line on load |
| Sync | each sequencer has its own BPM; a common start keeps equal BPMs locked; CLK out -> CLK in for exact lock |
