## Shape

- **Pictures are code against a tiny canvas interface** (`src/ui/gfx.h`: pixel, line, rect, circle,
  text). The device implements it with the M5Canvas sprite; the native tests implement it with a
  framebuffer that records out-of-bounds draws and can write PNGs (`test/test_pictures`, output in
  `.pio/pictures/`). So every picture is built, bounds-checked and looked at without the device.
- `src/ui/pictures.{h,cpp}`: one painter per module type (by type id), size-agnostic (works in the
  121 x 101 module-view block, in a place-menu thumbnail and as a patch-tile glyph), given the
  record, the live instance (monitors) or null, and the selected param (bold accent = emphasis).
  Picture maths reuses the modules' own functions (euclidHit, fold, scales) where they exist.
- `Drawing::Picture` marks a page that has one; the old FilterCurve / Envelope move to painters;
  Scope and Playhead stay as they are.
- Live pictures read the 2 monitor slots and redraw through the existing RedrawGate (<= 10 fps,
  only when a quantised monitor changed). Everything else is static: drawn only on a change.

## Tasks

1. Canvas interface, native framebuffer + PNG dump, device adapter, `Drawing::Picture` dispatch,
   emphasis + default ghost helpers; port VCF + ENV to painters (no look change beyond E/G).
2. Oscillator / LFO family: OSC (wave + harmonics + note name), VSO, FMO, SSW, HRM, FOR, VOS, ZOS,
   NOI, LFO (live phase dot + 90 deg), TRM, RND, CHS.
3. Envelope / drum family: AD, LPG, KCK, SNR, HAT, STR, MDL, RES, PRT, ENF, SLW, S&H.
4. Shapers / time / filters: FLD, OVD, CRU, ATN, DYN, RING, XFD, LAD, AWH, PHA, FLG, CHO, PSH,
   DLY, REV.
5. Sequencing / routing / IO: EUC ring, SEQ pitch bars, TRG/KIT hatch past LEN, TUR register, CLK
   pulses, QNT + KEYS scale strip, MUX/DMX/BRN/LGC route pictures, MIX/VCA/KNB bars, OUT meter,
   TLT XY, GRD engine labels + TONE page with XY pad + VOICE page filter/ADS picture.
6. Whole UI: value strip (bipolar fill from a centre mark, default tick), place-menu thumbnail,
   patch-tile glyphs that follow params, step blink on sequencer tiles.
7. New modules: ARP, CLP, PRC, VOW, EQ3 (DSP + tests + pictures).
8. Presets: a second PRESETS page; ~12 presets using the new modules; levels from the bench.
9. Device build size check, test bin, owner test script, spec + ledger.
