Cardputer modular: screen mockups

Mockups at 3× scale (2× for the side-by-side comparisons) of the real 240×135 screen. The 12×4 middle grid sits directly on the 12×4 middle keys, and the side icons sit level with esc tab fn ctrl on the left and del \ enter space on the right. Empty cells show their key letter faintly.

1 · Look: which direction?

Patch view (zoomed out), page 1, with your first patch. VCF is selected, so only its cables show, as dots in matching colours on the modules at the other end.

A · OP-1 dark

Black screen. Colours mark module type: orange = sound source, blue = modulator, white = processor/IO. Cable dots use a separate bright palette.

B · Pocket Operator LCD

Grey "segment LCD" look with one orange accent. Very TE, but colour-matched cable dots clash with the monochrome style.

Side keys in patch view (proposal):
esc file menu (save/load) · tab next page (shows 1/3) · fn+cell place module · ctrl+cell move module
del delete · \ undo · enter open module · space audition (hold to play a note)
Thin bars on the far left and right edges: CPU and RAM.

2 · Module view: VCF (zoomed in)

Top row = value strip. It shows the selected parameter's value. Keys 1–= jump to 12 coarse steps.

ctrl / space = fine −/+. Hold the parameter's key and tilt to sweep it.

Inputs (in) and outputs (out) show a dot in the cable's colour and the module at the other end. An output's amount (AMT) sits right next to it and is edited like any other parameter.

Spare cells hold a live drawing: the filter curve, wobbling with its LFO.

fn+pin = start or finish a cable · del on a pin = unpatch.

3 · Module view: ADSR

The envelope draws its own shape, and a dot runs along it while the gate is open.

A, D, S and R sit on the bottom row of keys. Attack is selected, so the top strip shows its value.

The output (OUT) has two cables (to VCA and VCF), so it shows two dots.

4 · Patching between two modules: which flow?

Zoomed in, you only see one module, so a cable needs a way to reach the other module.

A · Carry the cable

fn+LFO.OUT "picks up" a cable. Then esc to patch view, open VCF, and fn+CUT to drop it. The top strip reminds you what you're holding, and esc twice cancels.

B · Split view

In patch view, fn+LFO then fn+VCF opens both modules side by side, 6 columns each. Pick an output on one side and an input on the other. Faster for building, but each module gets only half the cells.
